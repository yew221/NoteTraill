# NoteTrail

NoteTrail 让你直接向自己的 Obsidian 知识库提问。点击回答中的引用，可以回到笔记原文核对；拖入文件或粘贴网页，也可以把新资料收进知识库。

## 安装桌面版

本源码包适用于 **macOS 26.6、Apple Silicon（arm64）**。打开包内的 `desktop/README.md`，按「从源码安装」完成运行环境安装、构建和启动。首次安装需要联网，无需预装 Node.js 或 Python。重新打开时，沿用原来的数据和桌面配置目录。

打开桌面后，从左下角设置连接自己的知识库，并配置云端大模型的 API 密钥。可以先找一篇熟悉的笔记，问一个能在里面找到答案的问题，再点击引用核对原句。拖入附件后，“原件已保存”表示文件已经收好；“可用于问答”表示正文已经可以检索。扫描件可能需要另附可读文字，旧版 `.doc` 请先转换为 `.docx`。

## 隐私、费用与备份

原件和历史保存在本机，API 密钥保存在 macOS 钥匙串。问答会把问题、所需资料片段、相关历史和适用的记忆发送给你选择的云端大模型。配置搜索服务后，应用可按需自动发送搜索词。连接测试、问答、关注复核和搜索都可能收费，应用不设金额上限。详情见包内的 `WEB_SEARCH.md`。

退出应用后，再分别备份知识库文件、应用数据和桌面配置。桌面配置包含其他知识库的应用数据、草稿和未发送附件。恢复后需重新填写密钥。备份、迁移与本机打包见 `desktop/README.md`。
